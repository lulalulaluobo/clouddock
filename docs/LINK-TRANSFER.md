# CloudDock 链接转存

已部署到 NAS：<http://192.168.2.61:7003/transfer>。

## 使用

1. 桌面侧边菜单或手机底部导航点击“链接转存”。
2. 粘贴夸克或百度分享链接，也可以粘贴带提取码的完整分享文案。没有包含提取码时，可在下方单独填写。
3. 点击“解析资源”，在结果卡片点击“转存”。
4. 勾选本次需要的资源，选择网盘保存目录；需要本地下载时，勾选“下载到飞牛”并选择飞牛目录。
5. 提交后在“下载进度”查看。夸克走 aria2，百度走飞牛官方百度网盘，均复用已有流程。

夸克需要设置 Cookie；百度需要在飞牛官方应用登录后，在 CloudDock 设置中获取授权。本次没有增加新的授权方式。
