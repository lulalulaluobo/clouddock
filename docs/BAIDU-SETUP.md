# 飞牛百度网盘授权与使用

适配功能自 CloudDock **1.1.0** 起内置，无需安装额外服务、填写配对码或复制百度 Cookie。当前版本使用 `lulalulaluobo/clouddock:1.3.0`；旧版 `1.0.0` 不包含此功能。

## 设置中获取授权

1. 在同一台飞牛的官方百度网盘应用登录百度账号。
2. 管理员进入 CloudDock「设置 → 飞牛百度网盘」，点击「获取飞牛百度网盘授权」。无需再点页面底部“保存设置”。
3. 页面显示连接状态及 NAS 会员状态。未登录时先去官方应用登录；切换百度账号后需重新点击获取授权。
4. 搜索百度资源，沿用原来的「转存 → 选择资源 → 选择保存目录」。百度目录和飞牛下载目录独立；开启“同时下载到飞牛”后，只提交本次勾选资源。
5. 在「下载进度 → 百度下载」查看进度。百度使用飞牛官方客户端下载，夸克继续使用 aria2。百度任务暂停、恢复在飞牛官方应用操作。

## Compose 配置

在基础 `compose.yaml` 同目录放置项目提供的 `compose.baidu.yaml`。配置 `.env`：

```dotenv
# 飞牛中登录官方百度应用的用户 UID，不是百度账号或 CloudDock 用户 ID
BAIDU_NAS_UID=1000
# 宿主机真实下载目录，与基础 Compose 挂载到 /downloads 的目录一致
NAS_DOWNLOAD_PATH=/vol3/1000/2T/飞牛影视
```

```bash
docker compose -f compose.yaml -f compose.baidu.yaml config --quiet
docker compose -f compose.yaml -f compose.baidu.yaml pull
docker compose -f compose.yaml -f compose.baidu.yaml up -d
```

覆盖配置只增加官方应用数据库目录和目录映射的只读挂载。官方应用必须已安装并登录，缺少挂载源时停止启动，不会创建假的空目录。下载路径必须在飞牛百度允许访问的目录范围内。默认支持根目录 ID `media`；多个根目录需额外配置 `BAIDU_HOST_ROOTS_JSON`，按 CloudDock 根目录 ID 映射宿主机路径。

后续升级、重建或停止服务也使用两份 `-f` 参数，避免基础配置覆盖百度挂载。百度下载由官方客户端完成，不能通过 aria2 获得飞牛专属下载权益。

CloudDock 读取当前绑定账号，每次请求获取最新凭据；凭据不返回前端、不写入镜像。授权配置只保存账号指纹，存于持久化 `config/fnos-baidu-binding.json`。只允许管理员操作，所有管理员共用该飞牛用户的百度账号。无需特权容器、Docker socket 或 SSH 密码。此功能仅适用于同机 fnOS 官方百度应用，版本升级后应重新验证兼容性。

## 测试

- 设置页获取授权，确认连接状态；未登录提示可理解。
- 百度分享只勾选一个文件，分别指定网盘目录和飞牛目录，确认只产生所选下载。
- 关闭“同时下载到飞牛”，确认仅转存；开启后在百度下载记录查看进度。
- 检查夸克转存、aria2、搜索频道及频道管理仍正常。
- 修改下载路径后确认本地不附加网盘目录前缀。首次使用建议选择小文件验证。

请求结果不确定时会停止自动重试，先在官方百度应用核对，避免重复转存或下载。
